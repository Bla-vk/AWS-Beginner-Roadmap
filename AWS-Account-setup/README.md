## Introducing Today's Project!

In this project, I'm going to set up an AWS account.

### Key tools and concepts

The key tools I used include AWS, Google Authenticator app. Key concepts I learnt include MFA and creating a AWS account.

### Challenges and wins

This project took me approximately 30 minutes. There were no challenging part.

## Creating My AWS Account

In this step, I'm going to start the signup process for an AWS account and verify my email

### Understanding the root user

I learned that a root user is the main owner of an account, a strong password is important because it stops unauthorized access to our aws account.

---

## Setting Up Billing and Payment

In this step, I'm going to choose an account plan and add billing information.

### Why AWS requires a payment method

I learned that AWS requires a payment method to verify that we are a real person and also for when our free plan expires.

---

## Completing Account Activation

In this step, I'm going to verify my identity and select a support plan.

### Identity verification and support plan

I verified my identity by typing in the verification code sent to my phone. The Basic support plan includes access to every aws services documentation.
